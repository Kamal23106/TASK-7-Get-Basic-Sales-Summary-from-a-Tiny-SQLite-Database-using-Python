# TASK-7-Get-Basic-Sales-Summary-from-a-Tiny-SQLite-Database-using-Python
This task is designed to help you gain practical experience in performing basic data analysis tasks using SQL and Python. The goal is to extract, manipulate, and visualize sales data stored in a small SQLite database. Let's break it down step-by-step:

1. Creating the SQLite Database (sales_data.db):
The first step is to create a small SQLite database file named sales_data.db. This database should contain a single table, typically named sales, where sales-related data will be stored.

The table should include columns such as:
product: Name of the product sold.
quantity: Quantity of the product sold.
price: Price per unit of the product.
This step simulates the creation of a sales database that would be common in many real-world scenarios.

2. Connecting to the SQLite Database in Python:
To interact with the database in Python, you'll use the built-in sqlite3 library. This library allows you to connect to the SQLite database and run SQL queries directly from Python code.


3. Writing SQL Query for Sales Summary:
The core of this task is writing a SQL query that extracts a summary of sales information, such as the total quantity sold and the total revenue generated for each product.

A typical query to achieve this would look something like:


SELECT product, SUM(quantity) AS total_qty, SUM(quantity * price) AS revenue
FROM sales
GROUP BY product;
Explanation of the Query:

SELECT product: This selects the product column from the sales table.
SUM(quantity) AS total_qty: This calculates the total quantity sold for each product.
SUM(quantity * price) AS revenue: This calculates the total revenue for each product by multiplying the quantity sold by the price per unit.
GROUP BY product: This groups the results by the product, so you get one row per product with its total quantity sold and revenue.

6. Visualizing the Data Using a Bar Chart:
To make the results more insightful, you can create a simple bar chart using matplotlib to visualize the revenue generated by each product.

The following code generates a bar chart:

import matplotlib.pyplot as plt
df.plot(kind='bar', x='product', y='revenue', title='Sales Revenue by Product')
plt.xlabel('Product')
plt.ylabel('Revenue')
plt.show()
Explanation:

kind='bar': Specifies that the chart will be a bar chart.
x='product': The x-axis will represent the products.
y='revenue': The y-axis will represent the total revenue for each product.
title, xlabel, and ylabel add labels and a title to the chart.
plt.show() displays the chart in your output.
